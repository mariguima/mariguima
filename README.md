## Featured projects

### Fall Detection Device (2026)
**Python · CNN · Kotlin · Android**

A system that watches over elderly users through a camera module of an ESP32-S3 board and detects falls with a CNN. When it sees one, it sends a real-time alert to a caregiver's Android app, where the caregiver can confirm if a fall actually occured and take appropriate measures.

- 
- Trained and built the fall detection model in Python
- Built the Android companion app in Kotlin and HTML
- Added a **caregiver confirmation step** to cut down on false alarms
- **Why I built it:** falls are a leading danger for older people living alone, and fast alerts can make a real difference

🔗 [Repository of the server](https://github.com/mariguima/server-fall-detection-app)
🔗 [Repository of the app](https://github.com/mariguima/Fall-detection-app)
🔗 [Repository of the camera/ESP32 code](https://github.com/mariguima/BYOP_camera)

### The Bridger C8: AgentVerse Hackathon (2026)
**Amazon Transcribe · Gemini API · Neo4j · AI**

An AI-powered web platform built in **24 hours** for the Workplace Trail. It helps information flow between departments and teams, so crucial knowledge doesn't get lost across emails, meetings, chats and scattered documents.

- Upload documents and track project progress
- Ask questions about colleagues' work and get AI-generated answers
- Transcribe in-person meetings and answer questions about them in real time
- Explore a **neural knowledge graph** showing how projects, documents and teams connect

**How it works:** Amazon Transcribe handles speech-to-text, the Gemini API answers queries, and Neo4j models and visualizes the data as a graph.

🔗 [Repository](https://github.com/ShawnNotFound/agentverse-hackathon)
🔗 [Devpost](https://devpost.com/software/c8-solution-to-cross-collaboration-and-breaking-down-silos)
